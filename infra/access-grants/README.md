# Access grant diffs land here — this IS the Terraform root module

This directory (not `infra/`) is what the CI/CD pipeline actually runs
`terraform init/plan/apply` against — see `backend.tf` for the state
backend + provider config. Terraform does not recurse into subdirectories,
so any generated file must live directly here to ever be applied.

Individual `.tf` files are generated by `agents/terraform_render.py` (one
per approved `access_grant` request) and reference the reusable modules in
`modules/` via a `../../modules/...` relative path — that's why this
directory is two levels below the repo root.

Nothing here is created directly by the agent against real infrastructure:
each file is proposed as a pull request, approved in ServiceNow, and only
applied by the CI/CD pipeline after a human merges the PR.
