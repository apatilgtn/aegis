# Access grant diffs land here

Files in this directory are generated by `agents/terraform_render.py` (one
per approved `access_grant` request) and reference the reusable modules in
`modules/` via a `../../modules/...` relative path — that's why this
directory is two levels below the repo root, matching `infra/access-grants/`.

Nothing here is created directly by the agent against real infrastructure:
each file is proposed as a pull request, approved in ServiceNow, and only
applied by the Cloud Build pipeline after a human merges the PR.
