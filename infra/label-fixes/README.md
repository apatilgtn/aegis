# Label fixes

Each `<request-id>.json` file here is generated by Aegis after a ServiceNow
approval and merged by a person. On merge, the `gcp-apply-label-fixes`
pipeline job runs `scripts/apply_label_fixes.py`, which adds only the
required labels that are still missing on the bucket. Existing labels are
never changed or removed, and the bucket is never created, imported or
managed by Terraform.
